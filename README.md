# 方位ノート

自宅に限らない複数の基準地点から、目的地の方位・方位角・距離を確認する日本語Webアプリです。

## 主な機能

- 検索、現在地、地図クリックによる基準地点・目的地の設定
- 名前付き基準地点の端末内保存とクイック切替
- 45度均等8方位、30/60度8方位の切替
- 測地計算による方位角・距離・方位境界線
- 基準地点と目的地の入れ替え、基準変更の直前1回Undo
- JSONバックアップの書き出し・読み込み
- 名前・生年月日の端末内プロフィール保存
- 九星気学の本命星と年盤による参考方位候補
- PWAマニフェストとスマートフォン対応

## 開発

```bash
npm install
npm run dev
```

品質確認:

```bash
npm run lint
npm run build
```

## データと外部サービス

保存地点と設定はブラウザ内に保存されます。恒久保存は保証されないため、設定画面からJSONバックアップを作成できます。

- 地図表示: MapLibre GL JS / OpenFreeMap
- 地図データ: OpenStreetMap contributors
- 地点検索: OpenStreetMap Nominatim（検索ボタンを押した時のみ、最大5件を取得）

本アプリは方位と距離の確認ツールであり、吉凶や移動時期を判定するものではありません。

個人向け方位は、立春を2月4日頃とする近似で本命星と移動年の年盤を求め、五黄殺・暗剣殺・本命殺・本命的殺・歳破を除外したうえで、五行が相生・比和となる方位を参考候補として表示します。月盤・日盤、正確な節入り時刻、月命星、流派固有の判断は含みません。
